# 0.3.0 release validation

Date: 2026-10-22 (Asia/Shanghai). Repository: `seasonHxy/hip3-oracle`.
Local conditions: macOS, Python 3.12.5, Hyperliquid SDK 0.24.0, Ruff 0.16.10.
Tests use temporary files, synthetic quotes, mocked exchange transport and an ephemeral loopback HTTP port.

## Evidence collected

- `python -m unittest discover -s tests`: 102 tests pass; covers existing pricing, publication and recovery behavior plus
  pause persistence, incident-ID matching, no-op status, read-only preflight, trust-metadata validation, v2-to-v3 migration,
  synthetic replay and actual-process SIGTERM handling.
- `ruff check src tests` and `ruff format --check src tests`: pass.
- `git diff --check`: pass.
- `python -m build --no-isolation`: builds both the 0.3.0 wheel and source distribution.
- Installed wheel `preflight` on the static demo: `ok=true`, `signed=false`, `submitted=false`, `stateWritten=false`.
- Synthetic replay: `matches=true`, `cycles=6`, `mismatchedLines=[]`; expected prices and rejection reasons also have independent assertions.
- `docker compose config --quiet`: pass; adds a 30-second stop grace period.

The source distribution includes example data and operator documentation. GitHub CI independently checks Python 3.11/3.12,
builds the container and runs an offline non-root smoke test; its actual run status must be checked for the release commit.
Local validation does not by itself establish remote CI success.

## Data provenance and scope

`examples/synthetic-replay.jsonl` is invented deterministic test data for `demo:SYNTH`. It contains no actual market history,
updater secrets, provider authentication headers or production state. Its six scenarios cover normal pricing, outliers,
staleness, weight concentration, market closure and a large price gap.

No real `setOracle`, `haltTrading`, order or other exchange mutation was submitted. This work does not validate an actual
Testnet DEX, provider credentials/permissions, multi-host fencing, corporate-action handling or production signing custody.

## Security finding during publication

Remote history contained four credential-theft assets that were absent from the trusted local baseline. The two malicious
workflows were disabled; the release tree excludes those assets while preserving history. Details and remaining exposure
investigation are recorded in [the incident report](../security/2026-10-22-upstream-incident.md).

## Operational compatibility

Scoped v2 references and pending requests remain intact when read; the next write upgrades state to v3. A v2-only writer
rejects v3, preventing an older binary from ignoring a persisted pause. Unscoped v1 state is not silently imported.
Local pause cannot retract a submitted action or halt a market, and `preflight` does not prove updater-key permissions.
